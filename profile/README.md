## What we build

MAD Producer helps make MAD-related information easier to find, understand, and build upon.

- Contest information, calendars, and archives
- MAD teams, creators, and community resources
- Documentation, guides, and references
- Open-source tools and infrastructure for the community

## Featured projects

| Project | Description |
| --- | --- |
| [MAD-Toolbox](https://github.com/MAD-Producer/MAD-Toolbox) | A creator toolkit for video and music downloads, media conversion, and task management. |
| [MAD-DOC](https://github.com/MAD-Producer/MAD-DOC) | Documentation and references for MAD / AMV creators. |
| [mad-store](https://github.com/MAD-Producer/mad-store) | A project hub for MAD-related resources and tools. |

## Get involved

Contributions are welcome, including documentation improvements, data updates, tooling, translations, and community resources.

If you have an idea or spot something that needs improvement, open an issue or submit a pull request in the relevant repository.
